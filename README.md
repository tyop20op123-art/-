# תובנה · כרטיסיות ידע

פיד אינסופי של כרטיסיות ידע בעברית (RTL), בגלילה אנכית מלאה כמו Reels.
קטגוריות: פילוסופיה · מדע - פיזיקה · מדע - ביולוגיה · פסיכולוגיה · טכנולוגיה · יהדות (אמונה).

- 46 כרטיסיות ערוכות + כ-180 כרטיסיות בחבילה שעובדת גם בלי רשת
- תוכן חי מוויקיפדיה, ספריא (כוזרי, מורה נבוכים, ספר העיקרים, תניא ועוד), Hacker News, arXiv ו-Open Library
- כרטיסייה שכבר נראתה לא חוזרת עד שנגמר כל התוכן החדש
- שמירה, "תובנה חזקה", שיתוף, "העמק עוד", הספרייה שלי, תצוגת ספר, יעד יומי ורצף
- חשבון (אימייל) שמסנכרן את השמורים בין מכשירים
- ניתנת להתקנה בטלפון (PWA) ועובדת אופליין

## 📱 הורדת האפליקציה לאנדרואיד

**[⬇️ הורדת tovana.apk](https://github.com/tyop20op123-art/-/releases/latest/download/tovana.apk)**

פותחים את הקובץ בטלפון ומאשרים "התקנה ממקורות לא ידועים".
הקובץ נבנה מחדש אוטומטית בכל עדכון (`.github/workflows/android.yml`).

## הפעלה כאתר (GitHub Pages)

1. ב-GitHub: **Settings ← Pages ← Source: Deploy from a branch ← main / (root) ← Save**.
2. אחרי דקה האתר זמין בכתובת `https://USERNAME.github.io/REPO/`.
3. פותחים בטלפון ← כפתור "התקנה" (אנדרואיד) או שיתוף ← "הוסף למסך הבית" (אייפון).
4. ל-APK אמיתי: מכניסים את הכתובת ב-pwabuilder.com ← Android.

## חשבונות ושמירה בענן

כניסה עם אימייל וסיסמה (Supabase). השמורים, "חזק!", תחומי העניין, הרצף ומה שכבר נראה נשמרים בחשבון ומסתנכרנים בין מכשירים.
החיבור מוגדר ב-[`js/backend-config.js`](js/backend-config.js), והטבלה וכללי האבטחה ב-[`supabase/schema.sql`](supabase/schema.sql) – כל משתמש רואה רק את הנתונים שלו.

## ✦ סקירת AI

כפתור הזהב בכרטיסייה (וגם בחלונית "העמק עוד") מבקש מ-Claude להסביר את הרעיון במילים הכי פשוטות:
משפט אחד, הסבר קצר, דוגמה מהחיים, למה זה חשוב, ומילון מושגים.

- רץ בפונקציית שרת של Supabase: [`supabase/functions/explain/index.ts`](supabase/functions/explain/index.ts)
- זמין למשתמשים מחוברים, עד 30 הסברים ביום למשתמש
- כל הסבר נשמר במטמון משותף, כך שכל כרטיסייה מוסברת (ומשולמת) פעם אחת בלבד
- **הפעלה:** Supabase ← Project Settings ← Edge Functions ← Secrets ← הוסיפו `ANTHROPIC_API_KEY`
  (מפתח מ-console.anthropic.com). עד אז הכפתור מציג "סקירת AI עוד לא הופעלה".

## שרת עם AI (אופציונלי)

```
npm install
npm start          # http://localhost:5173
```
עם `ANTHROPIC_API_KEY` השרת מעבד טקסט גולמי לכרטיסייה בעברית (Claude), ומאפשר arXiv ו-Open Library.

## מבנה

| קובץ | תפקיד |
|---|---|
| `js/seed.js`, `js/seed-emunah.js` | כרטיסיות ערוכות |
| `data/pack.json` | חבילת תוכן מוכנה (עובדת בלי רשת) |
| `js/sources.js` | מקורות חיים + עיבוד לכרטיסייה |
| `js/app.js` | פיד, מניעת חזרות, מעקב קריאה, יעד ורצף, ספרייה |
| `js/account.js`, `js/backend-config.js`, `supabase/schema.sql` | חשבונות וסנכרון |
| `sw.js`, `manifest.webmanifest`, `icons/` | התקנה ואופליין |
| `server.js` | שרת Node אופציונלי: עיבוד AI ו-proxy |
